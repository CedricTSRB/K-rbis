🔒 Zum Speichern auf der öffentlichen Webseite benötigst du einen GitHub Fine-grained Personal Access Token für das Repository CedricTSRB/K-rbis mit Contents: Read and write. Den Token nur hier eingeben, niemals weitergeben. Er wird nicht auf der Webseite gespeichert.

GitHub-Token erstellen ↗

✅ Verbunden. Änderungen werden direkt auf GitHub veröffentlicht. Screenshots bleiben in ihrer Originalauflösung – ohne Verkleinerung oder erneute Komprimierung.

Wähle bis zu 3 PNG-, JPG- oder WebP-Bilder auf einmal aus. Originalqualität bleibt erhalten.

Die Vorschaubilder erscheinen sofort. Zum Speichern anschließend unbedingt auf Auf Webseite veröffentlichen klicken und auf die Bestätigung warten.
